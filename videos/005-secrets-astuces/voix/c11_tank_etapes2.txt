Étape quatre : sur l'île, trouve la porte du bunker, et tape le code : zéro un, zéro trois, dix-sept. Étape cinq : à l'intérieur, rallume le courant, puis passe les portes. Tu es dans le bunker du président, plein de clins d'œil, comme une photo du président qui serre la main d'un extraterrestre. Étape six : assieds-toi au bureau, ouvre le tiroir, et décroche le téléphone. Une radio s'allume dans une autre pièce : écoute-la jusqu'au bout. Retourne au bureau : le document secret te donne le code du coffre, deux, neuf, sept, cinq. Dans le coffre : le pistolet Russo 1922, et une photo. Retourne-la : c'est l'indice qui ouvre le grand bunker.
